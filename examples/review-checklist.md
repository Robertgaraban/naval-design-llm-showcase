# Lista de revisión humana

[← Volver al caso](../README.md) · [Decisiones y revisión](../docs/04-decisiones-y-revision-humana.md)

Plantilla académica. No sustituye una revisión naval, normativa o de seguridad especializada.

## Identidad y procedencia

- [ ] El artefacto tiene ID, versión y estado.
- [ ] La fuente de cada requisito o parámetro está indicada.
- [ ] Los supuestos están separados de los datos documentados.
- [ ] No aparecen rutas locales, datos personales ni información no publicable.

## Significado y unidades

- [ ] La interpretación conserva la intención del requisito.
- [ ] Todos los valores cuantitativos tienen unidad.
- [ ] Objetivos, estimaciones y mediciones no se confunden.
- [ ] Las conversiones o redondeos quedan registrados.

## Trazabilidad y coherencia

- [ ] Cada requisito apunta a sus parámetros dependientes.
- [ ] Cada parámetro identifica la geometría o sistema afectado.
- [ ] Los documentos afectados están enumerados.
- [ ] La salida corresponde a la versión revisada de la entrada.
- [ ] No hay campos completados por el LLM sin fuente o marca de supuesto.

## Comunicación responsable

- [ ] El texto no presenta el vehículo como construido o probado.
- [ ] No convierte una generación de archivo en validación técnica.
- [ ] No afirma certificación, homologación o aprobación inexistente.
- [ ] Herramientas e instituciones no se presentan como patrocinadores.
